# Modèle de fiche de notion

Utiliser ce modèle pour les prochaines notions après qu’elles ont été étudiées.

```md
# Nom de la notion

## À quoi cela sert

## Idée essentielle

## Exemple minimal personnel

## Comparaison avec JavaScript / TypeScript

## Pièges

## À retenir

## Exercice associé

## Questions de révision
```

Le but est de reformuler avec ses propres mots. Le code complet reste dans le dépôt ;
la fiche explique surtout le raisonnement et les décisions importantes.
