# Exercices complémentaires

Ce dossier accueille uniquement les exercices complémentaires et les évaluations courtes.

L’exercice principal d’une notion de cours doit rester dans le dossier correspondant de `fundamentals/`. Un exercice complémentaire est proposé à la demande de l’apprenant ou lorsqu’une difficulté rencontrée justifie un entraînement supplémentaire.
